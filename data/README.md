# Data

The dataset is not stored in this repository (about 70 MB).
Download **India Hospital Readmission Dataset (2015-2024)** from Kaggle:
https://www.kaggle.com/datasets/digutlaranjithkumar/india-hospital-readmission-dataset-20152024

Place these five files in a folder named `All Data/` (in Colab: in `/content/All Data/` or in `MyDrive/All Data/`):
`admissions.csv`, `patients.csv`, `diagnoses.csv`, `billing.csv`, `hospitals.csv`
